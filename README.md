# Push_Swap

## Description
**Push_swap** is a 42 school project where our goal is to sort a list of integers using two stacks (Stack A and Stack B) and a limited set of operations (such as swapping elements or pushing them between stacks). 

The program takes a list of numbers as arguments, calculates the fastest way to sort them, and displays the list of commands used to achieve this. 

In this version of the project, our program must also accept flags to choose between different sorting strategies (from simple to complex ones) and a benchmark mode (`--bench`) to display statistics like the number of operations and the initial disorder of the numbers.

> **Status:** In Progress.
